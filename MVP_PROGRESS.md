# Release checklist

- [x] Accounts, authentication, ownership boundaries, and private stem delivery
- [x] Bounded uploads, validation, processing stages, retries, and idempotence
- [x] Responsive multi-track studio with autosave and project restoration
- [x] Shared playback, seek, mute, solo, volume, offsets, tempo, and pitch controls
- [x] Pitch-preserving tempo changes via SoundTouchJS
- [x] Stereo 44.1 kHz 16-bit WAV export
- [x] Backend regression tests and frontend typecheck
- [ ] Public deployment configuration, HTTPS, backups, monitoring, and non-default infrastructure credentials
- [ ] Email verification, password reset, collaboration, effects, automatic beat alignment, and MP3 export

This repository is release-ready for local/self-hosted evaluation. Public hosting still
requires the operational safeguards listed in [README.md](README.md#public-hosting).
